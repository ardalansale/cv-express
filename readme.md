![Express](https://img.shields.io/badge/Express-000?style=flat&logo=express&logoColor=white)

En webbapplikation för att hantera kurser i en CV‑databas.  
Byggd med Express, EJS och PostgreSQL.

## Publicerad webbplats
https://cv-express-9ovn.onrender.com

## GitHub‑repo
https://github.com/ardalansale/cv-express

## Funktionalitet
- Visa kurser  
- Lägg till och radera kurser  
- Validering av obligatoriska fält  
- Minimalistisk design  
- Serverrenderade vyer med EJS  

## Tekniker
- Node.js  
- Express  
- EJS  
- PostgreSQL  
- HTML, CSS  

## Kör lokalt
```bash
npm install
node app.js
```


Applikationen körs på:
http://localhost:3000
